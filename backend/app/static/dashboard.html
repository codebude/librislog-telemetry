What is this?

  • No personal data. Each installation sends a random, anonymous ID plus its version, operating system, architecture and runtime. No IPs, no paths, no library contents are stored.
  • One row per installation. The database keeps a single row per installation that is updated on each check-in, so the dataset stays small and bounded, it never grows unboundedly.
  • Breakdowns cover active installations. The versions, operating system, architecture and runtime charts only count installations that checked in during the last 30 days. Older, inactive installations are excluded (they are moved to a pruned table after a year without activity).
  • How to opt out. You can disable telemetry in LibrisLog's settings, see the docs. If you do, this server never hears from your installation again.
  • This page is public. Only aggregate counts are shown, never individual installations.
